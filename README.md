# 10초만

장비별 가동음 점검 흐름을 보여주는 시연용 웹앱입니다. 홈의 원형 버튼을 누르면 Fronius TPS 400i CMT 용접기의 3초 점검 시연이 시작되고, 준비한 녹음의 파형과 FFT가 분석 리포트로 열립니다.

## 실행

Node.js 20.12 이상이 필요합니다. 이 폴더에서 다음 명령을 실행하고 [http://localhost:3000](http://localhost:3000)을 엽니다.

```powershell
node server.js
```

## 시연 순서

1. **홈**에서 원형 버튼을 누릅니다. 원형 게이지가 3초 동안 찬 뒤 리포트가 바텀시트로 열리고 자동 저장됩니다. 진행 중 같은 버튼을 다시 누르면 점검이 취소됩니다. **다시 듣기**로 녹음을 재생하고, 아래로 내려가며 시간 파형, 전체 FFT 그래프와 공정 점검 예시를 확인할 수 있습니다.
2. **내 장비**에서 장비 카드를 옆으로 넘기고 카드를 누릅니다. 바텀시트에서 장비 정보와 최근 분석 요약을 보고, 아래로 내려가며 사양, 최근 한 달 진단 횟수, 주파수 비교, 다음 점검 항목과 이전 리포트를 읽습니다. 같은 조건의 기록이 두 건 이상 있으면 해당 주파수의 변화 추이도 볼 수 있습니다.
3. **설정**에서 닉네임을 변경하고, 저장 리포트를 열고 삭제하거나 텍스트로 내려받습니다. **보유장비 관리**의 `+`로 사진·이름·상세를 등록할 수 있습니다. 장비를 왼쪽으로 밀어 삭제 버튼을 표시한 뒤 버튼을 누르거나 한 번 더 왼쪽으로 밀면 장비가 목록에서 삭제됩니다.

용접기 리포트의 시간 파형과 FFT는 번들에 포함된 녹음에서 계산했습니다. 보호가스 유량과 스패터·험핑·용락은 후속 점검 항목으로 안내합니다. 다른 장비의 비교 그래프는 참고용으로 합성한 신호를 사용합니다. 닉네임·장비·리포트는 해당 브라우저에 저장되며 시연에는 마이크나 AI API 권한이 필요하지 않습니다. NFC 스티커에 넣은 장비 URL을 열면 해당 브라우저에 등록된 장비 정보를 표시합니다.

## 실측 개발 화면

이전 실측 개발 화면은 [http://localhost:3000/live.html](http://localhost:3000/live.html)에서 열 수 있습니다.

AI 설명을 사용하려면 이 폴더의 `.env` 파일에 `OPENAI_API_KEY`를 설정하고 서버를 다시 시작합니다. `OPENAI_MODEL`은 선택 설정입니다.

```dotenv
OPENAI_API_KEY=여기에_본인_API_키
```

휴대폰 브라우저에서 사용하려면 앱과 `/api/analyze`를 같은 HTTPS 주소에서 제공하고 마이크 권한을 허용합니다. 스마트폰에 연결된 외부 마이크가 있다면 내장 마이크로 입력을 전환하세요.

## NFC 스티커와 측정 위치 설정

1. 홈의 **측정 위치 설정 · 수동 측정**을 열고 **측정 위치 추가**에서 설비와 위치 이름을 등록합니다. 같은 설비에도 여러 위치를 등록할 수 있습니다.
2. 휴대폰에서 실제 사용할 HTTPS 주소로 앱을 연 뒤, 선택한 위치의 링크를 NFC 스티커에 URL 형식으로 기록합니다. Android Chrome에서는 **NFC 스티커에 쓰기**를 사용할 수 있고, 링크를 복사해 NFC 기록 앱으로 쓸 수도 있습니다.
3. 스티커를 해당 위치에 붙이고 정상 운전 조건을 입력해 그 위치에서 가동음을 10초간 등록합니다. 기존 설비별 기준음과 이력은 각 설비의 **기본 측정 위치**에 있습니다.

## 점검 방법

- **Android Chrome**에서는 큰 원형 버튼으로 NFC 읽기를 시작한 뒤 스티커에 태그합니다. 해당 위치의 정상 기준이 있으면 10초 녹음으로 이어지고, 최초 사용 시 브라우저가 NFC 또는 마이크 권한을 요청할 수 있습니다.
- **URL 태그로 앱을 여는 기기**에서는 스티커를 읽어 브라우저에서 위치 링크를 열고 **가동음 10초 측정 시작**을 누릅니다. 기준이 없는 위치는 먼저 정상 가동음을 등록합니다.
- **수동 측정**에서는 설정에서 같은 위치를 선택합니다. 어느 방식이든 기준을 등록할 때와 같은 운전 조건, 마이크 방향과 거리로 측정합니다.

정상 기준과 점검 이력은 측정 위치별로 해당 브라우저에 저장됩니다. 다른 휴대폰으로 같은 위치 링크를 열 수 있으며, 그 브라우저에서 사용할 정상 기준을 먼저 등록합니다. 녹음과 FFT는 브라우저에서 처리하고 AI 서버에는 설비·위치, 운전 조건, FFT 비교 요약을 전송합니다. API 연결이 실패하면 FFT 비교 결과를 보면서 AI 설명을 다시 요청할 수 있습니다.

화면의 ‘기준과 유사’와 ‘가동음 변화 감지’는 시제품의 음향 비교 기준으로 분류한 결과입니다. 설비 종류와 운전 조건에 따른 현장 검증이 필요합니다.
